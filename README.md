# agenda_contatos
Aplicação em Python, feita em dupla, para cadastrar, listar, buscar e remover contatos via terminanal.

## Funcionalidades
- Cadastrar um novo contato (nome, telefone e emaol)
- Listar todos os contatos cadastrados
- Buscar um contato pelo nome
- Remover um contato

## Como executar

´´´
pythin agenda.py
